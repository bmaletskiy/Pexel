# Pexel

Pexel — це простий крос-платформений редактор електронних таблиць (аналог Excel), розроблений на .NET MAUI з підтримкою арифметичних виразів та формул.

Додаток дозволяє створювати таблиці, вводити формули з посиланнями на комірки, автоматично перераховувати залежні значення та зберігати таблиці у форматі JSON.

---

## ✨ Features

### 📊 Table Management
- Створення таблиці (за замовчуванням 5×5)
- Додавання та видалення рядків
- Додавання та видалення стовпців
- Ідентифікація комірок у стилі Excel (A1, B2, C3 тощо)

### ✏️ Cell Editing
- Введення тексту, чисел або формул
- Подвійне натискання для редагування
- Автоматичний перерахунок при зміні значення

### 🧮 Formula Support
- Формули починаються зі знака `=`
- Посилання на інші комірки (наприклад: `=A1+B2`)
- Автоматичне оновлення залежних комірок
- Виявлення циклічних посилань
- Обробка помилок формул

---

## ➗ Arithmetic Operators

- `^` — піднесення до степеня  
- `*` — множення  
- `/` — ділення  
- `mod` — остача від ділення  
- `div` — цілочисельне ділення  
- `+` — додавання  
- `-` — віднімання  

---

## ⚖ Comparison Operators

- `=` — рівно  
- `<` — менше  
- `>` — більше  
- `<=` — менше або рівно  
- `>=` — більше або рівно  
- `<>` — не рівно  

---

## 💾 Save & Load

- Збереження таблиці у форматі JSON
- Завантаження раніше збережених таблиць

## 🧱 Tech Stack

- C#
- .NET MAUI
- ANTLR4 (парсинг математичних виразів)
- MVVM архітектура

---

## 🏗 Architecture

Проєкт побудований за принципом MVVM:

- **Model** — логіка комірок та обчислень
- **ViewModel** — обробка команд та перерахунок залежностей
- **View** — UI на .NET MAUI

ANTLR використовується для побудови синтаксичного дерева формул та обчислення виразів.
